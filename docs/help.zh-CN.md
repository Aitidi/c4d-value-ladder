# ValueLadder 帮助

[English](help.md) | **简体中文**

ValueLadder 为 Cinema 4D 2026 和 2027（Windows）的数值框加入 Houdini 风格的中键阶梯调值。

## 快速开始

1. 退出 C4D。
2. 把 `ValueLadder-x.y.z.zip` 中的 `ValueLadder` 文件夹复制到对应版本的 plugins 目录：
   - 2027：`%APPDATA%\Maxon\Maxon Cinema 4D 2027_XXXXXXXX\plugins\`
   - 2026：`%APPDATA%\Maxon\Maxon Cinema 4D 2026_XXXXXXXX\plugins\`

   提示：在 C4D 中点击 **编辑 → 偏好设置 → 打开偏好设置文件夹...**，可以直接找到正确的 `XXXXXXXX` 文件夹。
3. 启动 C4D。
4. 打开 **扩展 → ValueLadder Settings...**，勾选 **当前启用（本次会话）** 和 **启动时启用**。

**扩展 → ValueLadder** 前面出现勾选标记，就表示插件已经可以使用。

## 调整数值

1. 把鼠标移到属性管理器中的数值框上，例如对象的 **位置 Y**。
2. 按住**鼠标中键**，光标旁会弹出步长阶梯。
3. 上下移动，停在需要的步长上。
4. 左右移动：每移动 6 像素改变一个步长，向右增大，向左减小。
5. 松开中键，确认修改。

拖动过程中：

- 属性管理器和视图会实时更新。
- 光标到达屏幕边缘时会从另一侧绕回，可以继续拖动。
- 数值不会超出参数自身的最小值和最大值。

## 选择步长

阶梯显示设置中启用的步长（默认 1000、100、10、1、0.1、0.01、0.001），每次从最接近 1 的挡位开始。

| 参数类型 | 行为 |
| --- | --- |
| 距离、角度、百分比等小数 | 显示全部启用的挡位，步长按数值框显示的单位计算，如 cm、° |
| 整数（分段、数量） | 隐藏小于 1 的挡位 |
| 时间（帧） | 按整帧调整 |

## 适用范围

**支持**

- 对象、标签（包括对象属性中内嵌的标签页，如 Phong 角度）、材质与着色器
- 用户数据
- 工程设置、渲染设置与渲染效果
- 当前工具、视图设置、Take、图层
- XPresso 节点、域图层、选中的关键帧
- 节点材质（含 Redshift）和场景节点的输入端口，包括 X/Y/Z 向量行
- 偏好设置窗口

**不支持**

- 颜色、渐变、样条、复选框和下拉菜单
- 已有输入连线的节点端口
- 结构管理器、图片查看器和渲染队列
- 旁边没有参数名称的数值框

ValueLadder 通过数值框左侧的参数名称来识别参数。没有名称标签的数值框不会弹出阶梯，状态栏会显示原因。

## 撤销与取消

| 操作 | 效果 |
| --- | --- |
| 按住中键时点击右键 | 取消本次拖动，恢复原值 |
| 拖动后按 Ctrl+Z | 一步撤销整次拖动 |

例外：帧率等工程设置不会被 C4D 记录到撤销中。拖动过程中仍可右键取消，但确认后无法用 Ctrl+Z 撤销。

## 设置

打开 **扩展 → ValueLadder Settings...** 或 **编辑 → 偏好设置 → ValueLadder**。

| 设置 | 作用 |
| --- | --- |
| **当前启用（本次会话）** | 开启或关闭 ValueLadder，直到退出 C4D。**扩展 → ValueLadder** 是同一个开关 |
| **启动时启用** | 启动 C4D 时是否开启。修改它不影响当前会话 |
| **阶梯挡位** | 阶梯显示哪些步长：10000、1000、100、10、1、0.1、0.01、0.001、0.0001。至少保留一个，下一次拖动时生效 |

提示：关掉用不到的挡位，阶梯会更短、更好选。

## 常见问题

**按住中键没有反应。**

- 确认 **扩展 → ValueLadder** 已勾选，或在设置中勾选 **当前启用（本次会话）**。
- 鼠标要指在数字上，而不是参数名称或旁边的滑块上。
- 查看 C4D 窗口底部的状态栏：
  - *"no parameter label found"*：这个数值框没有可用的名称标签。
  - *"label not recognized"*：无法识别这个参数。
  - *"no numeric parameter found under the cursor"*：这个参数不是支持的数值类型。

**扩展菜单里没有 ValueLadder。**

- 确认目录结构是 `plugins\ValueLadder\`，`ValueLadder.pyp` 直接位于其中，而不是 `plugins\ValueLadder\ValueLadder\`。
- 打开 **扩展 → 控制台**，查看有没有提到 ValueLadder 的 Python 报错。

**插件行为异常或重复响应。**

- 确认只安装了一份，删除所有 plugins 目录中的旧版本。

**在节点编辑器中中键无法平移画布。**

- 正常情况下不会影响节点编辑器画布的中键平移。如果遇到，请按下方方式反馈。

**反馈问题**

在 <https://github.com/Aitidi/c4d-value-ladder/issues> 提交 issue，写明 C4D 版本、出问题的参数和状态栏提示。如需详细日志：设置 Windows 环境变量 `VALUELADDER_DEBUG=1`，重启 C4D 并复现问题，然后附上 `%TEMP%\valueladder_debug.log`。

## 更新与卸载

- **更新**：退出 C4D，用新版 `ValueLadder` 文件夹替换旧的，再启动 C4D。设置会保留。
- **卸载**：退出 C4D，删除 `plugins\ValueLadder` 文件夹。
